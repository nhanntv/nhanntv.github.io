隐私政策

最后更新：2026年8月

Hidden Cam Detect（“本应用”）是一款隐藏设备警觉与初步排查工具，帮助您查找隐藏摄像头、隐蔽录音设备和窃听装置。本隐私政策说明本应用处理和不处理哪些数据，以及如何保护您的隐私。Hidden Cam Detect 由 Hidden Cam Detect（“我们”）提供。

Hidden Cam Detect 秉持离线优先、隐私优先的原则。您的扫描结果完全在您的设备上处理。本应用没有扫描后端，您的扫描数据绝不会上传给我们或任何其他人。

我们不收集的数据

我们不会在任何服务器上收集、传输或存储以下任何内容。这些数据保留在您的设备上，唯一可能将其中任何内容带离您设备的，是由您自己选择导出的报告（参见“证据照片”）：

  • Wi-Fi 与网络扫描结果 — 在您本地网络中发现的 IP 地址、设备名称、端口和服务。
  • 蓝牙（BLE）扫描结果 — 附近正在广播的设备、信号强度和标识符。
  • 相机画面 — 镜头反光（glint）与红外视图中的画面会在您的设备上实时分析，绝不会发送给我们或任何其他人。当某项检测被确认时，本应用确实会把该画面的一张小尺寸证据照片保存在您的设备上，以便您日后重新找到该位置——照片具体存放在哪里、如何关闭以及如何删除，请参见下方的“证据照片”。
  • 传感器读数 — 磁力计和其他运动传感器的数值实时显示，不会保留在设备之外。
  • 扫描历史、证据照片与基线 — 仅存储在您设备上本应用的本地数据库和私有存储空间中。

由于这些数据绝不会发送给我们，我们无法查看、访问或共享这些数据。

我们使用的权限及原因

本应用仅在相应场景下、为特定检测目的请求设备权限。您可以授予或拒绝每一项权限，并可日后在设备设置中撤销。

  • 相机 — 用于检测隐藏摄像头的镜头反光（glint）和红外光。画面在您的设备上分析，绝不会被传输；已确认检测的证据照片仅保存在您的设备上（参见“证据照片”）。
  • 位置 / 附近 Wi-Fi（Android） — 操作系统要求，用于扫描您本地网络上的联网设备；如果您允许，还用于读取您当前所连 Wi-Fi 网络的名称，以便为一次扫描标注该名称。我们不会使用此权限追踪您的地理位置，网络名称也始终保留在您的设备上。（另外单独说明：Firebase 会根据您的 IP 地址推断出城市级别的大致位置——参见“诊断与分析”。）
  • 本地网络（iOS） — 用于发现您本地网络上的设备以进行扫描。
  • 蓝牙 — 用于扫描附近正在广播的设备。在 Android 上被标记为“绝不用于定位”，因此不会用于推断您的位置。
  • 运动传感器 — 用于读取磁场作为参考指标。此信号仅供参考。

诊断与分析

本应用使用两项相互独立的 Firebase 服务。它们有各自的开关，默认状态也不同，因此下面分别说明。

  • 崩溃报告与应用基础数据——默认开启。本应用崩溃时，Firebase Crashlytics 会发送一份报告。与此同时，Firebase Analytics 的 SDK 会自行收集少量标准指标：应用打开次数、会话开始与应用更新、应用版本、设备型号与语言、根据您的 IP 地址推断出的大致位置，以及由 Firebase 生成的应用安装标识符。该收集在应用启动时即开始，因此在您看到同意页面之前也会发生。
  • 应用使用分析——默认关闭。只有在您亲自开启后，本应用才会额外发送您打开了哪些界面，以及一份简短且固定的操作清单：开始扫描，完成或取消扫描（含得出的风险等级、发现的可疑设备数量以及扫描耗时），打开某个检测工具，查看升级页面，开始、完成或恢复购买，完成初次引导，以及导出 PDF 报告。

两个开关，两种不同的默认状态。崩溃报告与应用基础数据默认开启，您可以随时在设置 →“共享匿名诊断信息”中将其关闭。应用使用分析默认关闭，在您亲自开启之前一直处于关闭状态；开启方式为首次打开本应用时出现的同意页面，或之后在设置 →“共享应用使用分析”中开启。关闭其中任一开关都不会停用任何检测功能。这两项服务都不会用于跨应用追踪或广告（无 IDFA）。

我们把第一个开关称为“匿名”，是因为这些数据不包含姓名、电子邮件地址、账号或广告标识符，我们也从不试图据此判断您是谁。不过，我们宁愿说得准确，也不愿只说得让人安心：Firebase 会为您安装的这份应用分配一个标识符，并且始终能看到您的 IP 地址和每个事件的发生时间。如果您开启应用使用分析，一次扫描的风险等级和发现的可疑设备数量会连同该标识符一起发送。这是一项真实存在的取舍，您应当在决定之前知晓。

您的扫描结果绝不会上报给我们。您发现的设备清单、您的证据照片，以及您的相机、音频和传感器数据，都绝不会被这两项服务上传——无论以何种形式，也无论处于何种设置。这是我们不会改变的核心承诺。

应用使用分析：由代码保证，而不是靠一句承诺。使用分析层在技术上就无法携带网络名称（SSID）、BSSID 或 MAC 地址、IP 地址、主机名、设备名称、房间或网络标签、文件路径以及检测详情，因为它只接受数字、真/假值和取自封闭列表的选项——绝不接受自由文本，因此根本没有能让这类值通过的字段。界面名称只来自一份固定的静态界面清单，其中绝不含任何标识符；即便如此，只要某个值看起来仍像地址或标识符，整个事件都会被丢弃。通过这条途径可能离开您设备的、与扫描相关的值只有总体风险等级和可疑设备数量，而且仅限于应用使用分析处于开启状态时。

崩溃报告：一个我们如实说明的例外。崩溃报告不像分析事件那样是一份整齐的字段清单——要真正有用，它必须原封不动地携带本应用产生的技术错误信息和调用堆栈（stack trace），我们不会改写或过滤它们。因此，如果本应用在网络扫描过程中崩溃，错误文本中可能包含当时的技术片段——最常见的是一次失败连接留下的本地地址，例如属于您自己网络的 192.168.x.x 之类的数字。与其宣称一个我们无法保证的绝对说法，我们宁愿把这一点告诉您。也请明确它不是什么：它绝不是您的扫描结果，绝不是照片，也绝不是发现内容的清单；它只是一个在您自己的网络之外毫无意义的私有网络地址；而且只有在本应用当时确实崩溃时才会出现。如果您完全不想承担这种可能性，请在设置 →“共享匿名诊断信息”中将其关闭——所有检测功能都将照常工作。

检测数据更新

本应用可能通过安全的 HTTPS 连接下载公开的参考数据——例如硬件厂商（OUI）列表和已知可疑端口列表——以提高检测准确性。这些文件来自我们的网站托管服务以及 Firebase Remote Config。这仅为下载操作：在这些更新过程中绝不会发送任何扫描数据。与任何下载一样，服务器会看到请求本身（您的 IP 地址，对于 Remote Config 还包括上文所述的应用安装标识符），文件也正是因此才能送达您的设备。

应用内购买

本应用提供可选的付费订阅（“Pro”）。付款完全由 Apple App Store 或 Google Play 处理。我们不会接收或存储您的支付卡信息。购买和订阅状态通过商店的收据机制进行验证。有关您的付款信息如何处理，请参阅相应商店的隐私政策。

我们使用 Qonversion 来管理和验证订阅。Qonversion 会接收您的购买和订阅状态，以及一个匿名的安装标识符，该标识符不含姓名、电子邮件地址或广告标识符。它不会接收您的支付卡信息。请参阅 Qonversion 的隐私政策：https://qonversion.io/privacy。

该标识符必须在重新安装本应用后依然存在——否则您已经付过款的购买将无法恢复——因此它在两个平台上以不同方式生成：

  • iOS — 由本应用生成并保存在设备钥匙串（Keychain）中的一个随机值。由于该钥匙串条目被标记为通过 iCloud 同步，同一标识符也可能出现在登录了您 Apple 账户的其他设备上，这正是购买能够随您转移到新 iPhone 或 iPad 的原因。
  • Android — 由您设备的 Android ID 派生而来：先将其与内置于本应用中的一个固定密钥组合，再对结果进行哈希（SHA-256）。Android ID 本身绝不会离开您的设备，只有哈希值会被使用。如果无法读取 Android ID，本应用会改用一个随机值。

证据照片

当镜头反光视图确认一项检测时，本应用会保存产生该结果的相机画面的一张小尺寸照片。这样做的用意很实际：扫描告诉您那里有东西，而照片则让您事后能重新找到同一位置。

  • 照片存放在哪里。存放在您设备上本应用自己的私有存储空间中——不会进入您的相册或相机胶卷，因为那里其他应用也能看到。在 iOS 上，本应用会要求系统将该文件夹排除在 iCloud 备份之外；在 Android 上，本应用被完全排除在系统备份之外。
  • 照片留在您的设备上。证据照片绝不会上传给我们或任何其他人，也绝不会附加到诊断或分析数据中。
  • 除非您导出或分享报告。如果您选择将一次扫描导出为 PDF，该次扫描的证据照片会包含在文档中，因为正是这些照片让报告成为证据。从那一刻起文件就属于您：您把它发给谁，谁就能看到这些照片。在您主动要求之前，不会导出任何内容。
  • 您可以关闭它。保存证据照片默认开启。您可以随时在设置 →“保存检测画面”中将其关闭；扫描仍可正常进行，只是发现结果不再附带照片。
  • 您可以删除它们。从历史记录中删除某次扫描会一并删除该次扫描的照片，清空历史记录则会删除全部照片。设置 →“删除全部已保存画面”可一次性移除所有已存储的照片，卸载本应用则会连同其他所有数据一起删除它们。

通知

如果您允许通知，本应用会向 Firebase Cloud Messaging 注册，以便我们可以偶尔发送产品消息，例如扫描提醒或更新资讯。注册会为本应用的此次安装生成一个通知令牌，由 Google 的消息服务保管；它不会与您的姓名或电子邮件地址关联。通知内容由我们撰写，绝不会包含您扫描中的任何内容。您可以随时在本应用的设置或您的设备设置中关闭通知。

本地存储

本应用使用设备上的数据库、私有文件存储和偏好设置，将您的扫描历史、基线、证据照片和设置（例如主题、语言和已启用的模块）本地存储在您的设备上。此信息不会同步到任何服务器。

儿童隐私

本应用并非面向 13 岁以下（或您所在司法管辖区要求的最低年龄，例如欧盟部分地区为 16 岁）的儿童。我们不会在知情的情况下收集儿童的个人信息。

您的权利

根据您所在地的不同，您可能依据 GDPR 或 CCPA 等法律享有相关权利，包括访问或删除您个人数据的权利。由于本应用不会在任何服务器上收集或存储您的扫描数据或个人数据，您的所有数据都保存在您的设备上。删除本应用即可移除这些数据，包括您的扫描历史、您的证据照片和您的设置。您也可以随时在应用内删除您的扫描历史和已保存的证据照片。您可随时在设置中关闭崩溃报告与应用基础数据，也可随时在设置中开启或关闭应用使用分析。
