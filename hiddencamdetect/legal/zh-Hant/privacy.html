隱私權政策

最後更新日期：2026年8月

HiddenCamDetect（下稱「本App」）是一款提升隱藏裝置警覺與初步篩查的工具，協助您查找隱藏式攝影機、隱蔽錄影裝置及竊聽裝置。本隱私權政策說明本App處理與不處理哪些資料，以及您的隱私如何受到保護。HiddenCamDetect 由 HiddenCamDetect（下稱「我們」）提供。

HiddenCamDetect 秉持離線優先與隱私優先原則。您的掃描結果完全在您的裝置上處理。本App沒有掃描後端伺服器，您的掃描資料絕不會上傳給我們或任何其他人。

我們不會收集的資料

我們不會在任何伺服器上收集、傳輸或儲存以下任何資料。這些資料留存於您的裝置上，唯一可能將其中任何資料帶離您裝置的，是由您自行選擇匯出的報告（參見「證據照片」）：

  • Wi-Fi 與網路掃描結果 — 在您本機網路上探索到的 IP 位址、裝置名稱、連接埠及服務。
  • 藍牙（BLE）掃描結果 — 附近正在廣播的裝置、訊號強度及識別碼。
  • 相機畫面 — 鏡頭反光與紅外線檢視中的畫面，均即時於您的裝置端分析，絕不會傳送給我們或任何其他人。當某項偵測獲得確認時，本App確實會將該畫面的一張小尺寸證據照片儲存於您的裝置上，以便您日後重新找到該位置——照片確切存放於何處、如何關閉以及如何刪除，請參見下方的「證據照片」。
  • 感測器讀數 — 磁力計及其他動作感測器的數值僅即時顯示，不會留存於裝置外。
  • 掃描歷史、證據照片與基準值 — 僅儲存於您裝置上本App的本機資料庫及私有儲存空間中。

由於這些資料絕不會傳送給我們，我們無法看到、存取或分享這些資料。

我們使用的權限及其原因

本App僅在特定情境下，並為特定的偵測目的請求裝置權限。您可以個別授予或拒絕每一項權限，並可日後在您的裝置設定中撤銷。

  • 相機 — 用於偵測隱藏式攝影機的鏡頭反光（閃光）及紅外線。畫面於您的裝置端分析，絕不會傳輸出去；已確認偵測的證據照片僅儲存於您的裝置上（參見「證據照片」）。
  • 位置／鄰近 Wi-Fi（Android） — 作業系統要求此權限以掃描您本機網路上的連網裝置；若您允許，亦用於讀取您目前所連 Wi-Fi 網路的名稱，以便為該次掃描標註此名稱。我們不會使用此權限追蹤您的地理位置，網路名稱也始終留存於您的裝置上。（另行說明：Firebase 會依您的 IP 位址推估城市層級的大略位置——參見「診斷與分析」。）
  • 本機網路（iOS） — 用於探索您本機網路上的裝置以進行掃描。
  • 藍牙 — 用於掃描附近正在廣播的裝置。在 Android 上，此項標記為「絕不用於定位」，因此不會用於推斷您的位置。
  • 動作感測器 — 用於讀取磁場作為參考指標。此訊號僅供參考。

診斷與分析

本App使用兩項彼此獨立的 Firebase 服務。兩者有各自的開關，預設狀態也不同，因此以下分別說明。

  • 當機報告與應用程式基本資料——預設為開啟。本App當機時，Firebase Crashlytics 會傳送一份報告。同時，Firebase Analytics 的 SDK 會自行收集少量標準量測資料：應用程式開啟次數、工作階段開始與應用程式更新、應用程式版本、裝置型號與語言、依您的 IP 位址推估的大略位置，以及由 Firebase 產生的應用程式安裝識別碼。此項收集自App啟動時即開始，因此在您看到同意畫面之前也會發生。
  • 應用程式使用分析——預設為關閉。唯有在您親自開啟後，本App才會額外傳送您開啟了哪些畫面，以及一份簡短且固定的操作清單：開始掃描、完成或取消掃描（含所得出的風險等級、發現的可疑裝置數量以及掃描耗時）、開啟某項偵測工具、檢視升級畫面、開始、完成或還原購買、完成初次導覽，以及匯出 PDF 報告。

兩個開關，兩種不同的預設狀態。當機報告與應用程式基本資料預設為開啟，您可隨時在「設定」→「分享匿名診斷資料」中將其關閉。應用程式使用分析預設為關閉，在您親自開啟之前始終保持關閉；開啟方式為首次開啟本App時出現的同意畫面，或日後在「設定」→「分享應用程式使用分析」中開啟。關閉其中任一開關都不會停用任何偵測功能。這兩項服務皆不會用於跨App追蹤或廣告（無 IDFA）。

我們之所以稱第一個開關為「匿名」，是因為這些資料不含姓名、電子郵件地址、帳號或廣告識別碼，我們也從不試圖藉此推斷您是誰。不過，我們寧可說得精確，也不願只說得令人安心：Firebase 會為您安裝的這份App指派一組識別碼，並且始終能看到您的 IP 位址與每個事件的發生時間。若您開啟應用程式使用分析，單次掃描的風險等級與發現的可疑裝置數量會連同該識別碼一併傳送。這是一項真實存在的取捨，您應在決定前先行知悉。

您的掃描結果絕不會回報給我們。您所探索到的裝置清單、您的證據照片，以及您的相機、音訊與感測器資料，都絕不會被這兩項服務上傳——不論以何種形式，也不論處於何種設定。這是我們始終不變的核心承諾。

應用程式使用分析：由程式碼保證，而非僅憑一句承諾。使用分析層在技術上就無法夾帶網路名稱（SSID）、BSSID 或 MAC 位址、IP 位址、主機名稱、裝置名稱、房間或網路標籤、檔案路徑以及偵測詳情，因為它僅接受數字、真／假值與取自封閉清單的選項——絕不接受自由輸入的文字，因此根本沒有可供這類值通行的欄位。畫面名稱僅來自一份固定的靜態畫面清單，其中絕不含任何識別碼；即使如此，只要某個值看起來仍像位址或識別碼，整個事件都會被丟棄。經由這條途徑有可能離開您裝置、且與掃描相關的值，只有整體風險等級與可疑裝置數量，而且僅限於應用程式使用分析處於開啟狀態時。

當機報告：一個我們如實說明的例外。當機報告不像分析事件那樣是一份整齊的欄位清單——若要真正有用，它必須原封不動地帶著本App所產生的技術錯誤訊息與呼叫堆疊（stack trace），我們不會改寫或過濾它們。因此，若本App在網路掃描過程中當機，錯誤文字中可能包含當下的技術片段——最常見的是一次失敗連線所留下的本機位址，例如屬於您自己網路的 192.168.x.x 之類的數字。與其宣稱一個我們無法保證的絕對說法，我們寧可把這一點告訴您。也請明確這不是什麼：它絕不是您的掃描結果，絕不是照片，也絕不是發現內容的清單；它只是一個在您自己的網路之外毫無意義的私有網路位址；而且唯有本App當下確實當機時才會出現。若您完全不想承擔這種可能性，請在「設定」→「分享匿名診斷資料」中將其關閉——所有偵測功能都會照常運作。

偵測資料更新

本App可能透過安全的 HTTPS 連線下載公開的參考資料，例如硬體供應商（OUI）清單及已知可疑連接埠清單，以提升偵測準確度。這些檔案來自我們的網站託管服務以及 Firebase Remote Config。此為僅下載作業：在這些更新過程中絕不會傳送任何掃描資料。與任何下載一樣，伺服器會看到請求本身（您的 IP 位址，就 Remote Config 而言還包括上文所述的應用程式安裝識別碼），檔案也正是因此才得以送達您的裝置。

App 內購買

本App提供選用性的付費訂閱（「Pro」）。付款完全由 Apple App Store 或 Google Play 處理。我們不會接收或儲存您的付款卡片詳細資料。購買與訂閱狀態係透過商店的收據機制進行驗證。關於您的付款資訊如何處理，請參閱適用商店的隱私權政策。

我們使用 Qonversion 來管理與驗證訂閱。Qonversion 會接收您的購買與訂閱狀態，以及一組匿名的安裝識別碼，該識別碼不含姓名、電子郵件地址或廣告識別碼。它不會接收您的付款卡片詳細資料。請參閱 Qonversion 的隱私權政策：https://qonversion.io/privacy。

該識別碼必須在重新安裝本App後依然存在——否則您已付款的購買將無法還原——因此它在兩個平台上以不同方式產生：

  • iOS — 由本App產生並保存在裝置鑰匙圈（Keychain）中的一組隨機值。由於該鑰匙圈項目被標記為透過 iCloud 同步，同一組識別碼也可能出現在登入您 Apple 帳戶的其他裝置上，這正是購買能夠隨您轉移到新 iPhone 或 iPad 的原因。
  • Android — 由您裝置的 Android ID 衍生而來：先將其與內建於本App中的一組固定密鑰組合，再對結果進行雜湊（SHA-256）。Android ID 本身絕不會離開您的裝置，只有雜湊值會被使用。若無法讀取 Android ID，本App會改用一組隨機值。

證據照片

當鏡頭反光檢視確認一項偵測時，本App會儲存產生該結果的相機畫面的一張小尺寸照片。這樣做的用意很實際：掃描告訴您那裡有東西，而照片則讓您事後能重新找到同一個位置。

  • 照片存放在哪裡。存放於您裝置上本App自己的私有儲存空間中——不會進入您的相片圖庫或相機膠卷，因為那裡其他App也看得到。在 iOS 上，本App會要求系統將該資料夾排除於 iCloud 備份之外；在 Android 上，本App已被完全排除於系統備份之外。
  • 照片留在您的裝置上。證據照片絕不會上傳給我們或任何其他人，也絕不會附加至診斷或分析資料中。
  • 除非您匯出或分享報告。若您選擇將一次掃描匯出為 PDF，該次掃描的證據照片會包含在文件中，因為正是這些照片讓報告成為證據。從那一刻起檔案就屬於您：您把它傳給誰，誰就能看到這些照片。在您主動要求之前，不會匯出任何內容。
  • 您可以關閉它。儲存證據照片預設為開啟。您可隨時在「設定」→「儲存偵測畫面」中將其關閉；掃描仍可正常進行，只是發現結果不再附帶照片。
  • 您可以刪除它們。從歷史記錄中刪除某次掃描會一併刪除該次掃描的照片，清除歷史記錄則會刪除全部照片。「設定」→「刪除全部已儲存畫面」可一次移除所有已儲存的照片，解除安裝本App則會連同其他所有資料一起刪除它們。

通知

若您允許通知，本App會向 Firebase Cloud Messaging 註冊，以便我們偶爾傳送產品訊息，例如掃描提醒或更新消息。註冊會為本App的這次安裝產生一組通知權杖，由 Google 的訊息服務保管；它不會與您的姓名或電子郵件地址連結。通知內容由我們撰寫，絕不會包含您掃描中的任何內容。您可隨時在本App的設定或您的裝置設定中關閉通知。

本機儲存

本App使用裝置端資料庫、私有檔案儲存空間及偏好設定，將您的掃描歷史、基準值、證據照片及設定（例如主題、語言及啟用的模組）儲存於您的裝置本機上。這些資訊不會同步至任何伺服器。

兒童隱私

本App並非以未滿 13 歲（或您所在管轄區所要求的最低年齡，例如歐盟部分地區為 16 歲）的兒童為對象。我們不會在知情的情況下收集兒童的個人資訊。

視您的居住地而定，您可能依據 GDPR 或 CCPA 等法律享有相關權利，包括存取或刪除您個人資料的權利。由於本App不會在任何伺服器上收集或儲存您的掃描資料或個人資料，您的所有資料皆存放於您的裝置上。刪除本App即可移除這些資料，包括您的掃描歷史、您的證據照片與您的設定。您也可以隨時在App內刪除您的掃描歷史與已儲存的證據照片。您可隨時在「設定」中關閉當機報告與應用程式基本資料，也可隨時在「設定」中開啟或關閉應用程式使用分析。
